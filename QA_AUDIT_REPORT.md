## 5. Критические ошибки P0

### BUG-001: Кнопка "Add vendor" не создаёт поставщика

**Раздел:** Documents → New Request → Add vendor

**Приоритет:** P0 — критическая проблема, блокирует основной пользовательский сценарий.

**Шаги воспроизведения:**
1. Зарегистрироваться и войти в аккаунт
2. Перейти на страницу Documents
3. Заполнить поле "Company name" в форме добавления поставщика
4. Нажать кнопку "Add vendor"
5. Проверить выпадающий список "Choose vendor"

**Ожидаемый результат:** Новый поставщик добавляется в выпадающий список и появляется в библиотеке документов.

**Фактический результат:** Поставщик не добавляется. Выпадающий список остаётся пустым ("Choose vendor"). Нет сообщений об ошибке или успехе.

**Доказательства:**
- URL: https://bradford7364123.pythonanywhere.com/documents/
- JS-ошибок в консоли нет
- HTTP-ошибок нет
- Поле "Company name" сохраняет значение после клика (форма не очищается)
- В выпадающем списке только "Choose vendor"

**Предполагаемая причина:** Обработчик нажатия кнопки "Add vendor" не вызывает сохранение данных или не обновляет UI после успешного создания.

**Рекомендация:** Проверить view-функцию и шаблон формы добавления поставщика. Убедиться, что POST-запрос обрабатывается и страница перезагружается с обновлённым списком.

**Критерий исправления:** После нажатия "Add vendor" новый поставщик появляется в выпадающем списке "Choose vendor" и в библиотеке документов.

## 6. Ошибки высокой важности P1

### BUG-002: Горизонтальная прокрутка на планшетах

**Раздел:** Главная страница (адаптивность)

**Приоритет:** P1 — нарушение пользовательского опыта на распространённых устройствах.

**Шаги воспроизведения:**
1. Открыть сайт на разрешении 1024x768 или 768x1024
2. Попробовать горизонтально прокрутить страницу

**Ожидаемый результат:** Страница соответствует ширине экрана, нет горизонтальной прокрутки.

**Фактический результат:** Присутствует горизонтальная прокрутка (document.scrollWidth > clientWidth).

**Доказательства:**
- 1024x768: hasHorizontalScroll = true
- 768x1024: hasHorizontalScroll = true
- 1920x1080, 1366x768, 390x844, 360x800: нет горизонтальной прокрутки

**Рекомендация:** Проверить CSS контейнеров на переполнение, уменьшить ширину элементов или добавить `overflow-x: hidden` на body.

**Критерий исправления:** На разрешениях 1024x768 и 768x1024 нет горизонтальной прокрутки.

### BUG-003: Навигация недоступна на мобильной домашней странице

**Раздел:** Главная страница (мобильная версия)

**Приоритет:** P1 — пользователи мобильных устройств не могут перейти на ключевые страницы.

**Шаги воспроизведения:**
1. Открыть главную страницу на мобильном устройстве (390x844, 360x800)
2. Попытаться найти ссылки "How it works", "Pricing", "Sign in"

**Ожидаемый результат:** Навигационные ссылки доступны через гамбургер-меню или отображаются на экране.

**Фактический результат:** На мобильной версии видна только кнопка "Start free". Остальные ссылки навигации скрыты, гамбургер-меню не обнаружено.

**Доказательства:**
- URL: https://bradford7364123.pythonanywhere.com/ (390x844)
- В тексте страницы только "Start free" в навигации
- Нет элемента меню/гамбургера

**Рекомендация:** Добавить гамбургер-меню для мобильных устройств или обеспечить отображение навигационных ссылок.

**Критерий исправления:** На мобильных устройствах доступны все основные навигационные ссылки.

## 15. Предполагаемые причины дефектов

1. **BUG-001, BUG-004:** Обработчики форм добавления поставщика и имущества не сохраняют данные или не обновляют UI после submission. Возможно, отсутствует обработка POST-запроса в шаблоне или view.
2. **BUG-002:** CSS-контейнеры имеют фиксированную ширину, превышающую ширину экрана на планшетах.
3. **BUG-003:** Отсутствует мобильная навигация (гамбургер-меню) на домашней странице.
